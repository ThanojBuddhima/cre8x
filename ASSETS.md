# Assets and licenses

SYNQ uses procedural geometry and open fonts. No paid 3D kits, photogrammetry, or stock-photo UI backgrounds.

## Fonts

- [Geist Variable](https://www.npmjs.com/package/@fontsource-variable/geist) — SIL Open Font License
- [IBM Plex Sans](https://www.npmjs.com/package/@fontsource/ibm-plex-sans) — SIL Open Font License
- [Instrument Serif](https://www.npmjs.com/package/@fontsource/instrument-serif) — SIL Open Font License

## Icons

- [Lucide](https://lucide.dev) — ISC License

## 3D

All buildings, vehicles, roads, rail, and air corridors are generated in Three.js at runtime (`src/scenes/CorridorTwin/CorridorTwin.tsx`). No GLB/GLTF files are bundled.

## UI primitives

Button, dialog, and slot behaviour follow the shadcn/ui + Radix pattern (MIT).
